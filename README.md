# Aroma Café — mini proyecto web

Proyecto educativo que integra HTML, CSS y JavaScript en una landing page para una cafetería ficticia.

## Archivos
- `index.html`: estructura y contenido semántico.
- `styles.css`: diseño visual, distribución y adaptación a móvil.
- `script.js`: carrito interactivo, cantidades, eliminación de productos, mensajes y cambio de tema.

## Cómo ejecutarlo
1. Descomprime la carpeta.
2. Mantén los tres archivos juntos.
3. Abre `index.html` en un navegador moderno.
4. Se requiere conexión a internet para cargar las fotografías y la tipografía externas.

## Qué demuestra cada tecnología
- HTML: secciones, navegación, tarjetas de productos, botones y carrito.
- CSS: paleta, tipografía, diseño responsive, estados hover y tema oscuro.
- JavaScript: eventos de clic, renderizado dinámico del carrito, cálculo del total, menú móvil y notificaciones.

Nota: es una demostración de front-end. No procesa pagos ni guarda pedidos en un servidor.
